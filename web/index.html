Port not listed or install fails?
  • Install the WCH CH34x / CH9102 driver (macOS/Windows), then re-plug.
  • Try another cable: many are charge-only.
  • Hold the side button B while plugging in to force download mode.
  • Only one program can use the port. Close other tabs and serial monitors.
Connect your stick to continue

Plug it in over USB and press Connect stick. Settings are read from and saved to the device.

    First trade checklist

    1. Install firmware, connect, set Wi-Fi.
    2. Generate a wallet and send ~0.05 SOL to it.
    3. Leave Armed off. Press A, A: should show SIM OK.
    4. Arm, buy the minimum size, then sell. The position screen stays up (even after a reboot) until the token is sold.

    Risks

    Memecoins can go to zero or be impossible to sell. Slippage, fees and failed transactions cost money. This is experimental software with no warranty.
